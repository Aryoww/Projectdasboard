SOP PRAKTIS LAPANGAN ELECTRICAL ROOM PT MUSASHI AUTO PARTS INDONESIA

SOP Praktis Saat Berada di Dalam Electrical Room A

Panduan Teknis Eksekusi Kabel, Ping Test, Software Modbus, dan Verifikasi Angka

Langkah 1: Pemeriksaan Fisik & Sambungan

1. Cari port Ethernet tempat kabel LAN Electrical Room A dicolokkan. Pastikan lampu LINK (hijau) menyala stabil.
2. Cari modul gateway konverter (Schneider Link150 / EGX). Pastikan lampu Power menyala dan lampu Tx/Rx serial berkedip-kedip.

Langkah 2: Uji Jaringan dari Laptop Commissioning

1. Colokkan kabel LAN laptop ke switch LAN pabrik. Atur IP laptop satu subnet dengan gateway (misal IP laptop 10.41.47.200).
2. Buka Command Prompt, ketik: ping 10.41.47.122 -t (Reply time < 5ms, loss 0%).
3. Uji Port 502 Modbus via PowerShell: Test-NetConnection -ComputerName 10.41.47.122 -Port 502 (Harus True).

Langkah 3: Pengujian Baca Register via Software Modbus

Gunakan software QModMaster atau Modbus Poll:
• Mode: Modbus TCP, IP = [IP Gateway], Port = 502, Slave ID = 1.
• Function Code: 03 (Read Holding Registers), Format: Float 32 (Big-Endian / ABCD).
• Address: 3020 (Voltase L-L) atau 3060 (Daya Aktif kW). Tekan Read/Poll.

KURIKULUM BELAJAR 1: TEKNIK KELISTRIKAN PT MUSASHI AUTO PARTS INDONESIA

Materi Belajar Wajib 1: Konsep Kelistrikan 3-Fasa & Power Meter

Fundamental Elektrikal yang Wajib Anda Kuasai Agar Paham Setiap Angka di Dashboard

1. Listrik 3-Fasa di Industri

Pabrik PT Musashi menggunakan sistem 3-fasa (Fasa R, S, T dan Netral N) untuk menyuplai motor industri besar.
• Tegangan Fasa-Netral (V L-N): 220 Volt.
• Tegangan Fasa-Fasa (V L-L): V L-L = V L-N x 1.732 = 380 Volt.
• Pada Gardu Schneider 20kV, tegangan menengah sebelum transformator adalah 20.000 Volt.

2. Tiga Jenis Daya Listrik (Segitiga Daya)

• Daya Nyata / Semu (S) - Satuan kVA: Kapasitas total yang disuplai PLN/trafo. Trafo Factory 1 berkapasitas total 7.750 kVA.
• Daya Aktif (P) - Satuan kW: Daya riil yang menghasilkan kerja mekanik/putar. P = 1.732 x V x I x Cos φ. Ini angka utama dashboard Anda.
• Daya Reaktif (Q) - Satuan kVAR: Daya pembentuk medan magnet belitan motor dan trafo.

3. Mengapa Power Factor (Cos φ) Sangat Krusial?

• Perbandingan daya aktif dan nyata: Cos φ = P / S (antara 0 sampai 1.0).
• Batas minimal PLN adalah 0.85. Jika di bawah 0.85, PLN menagih Denda kVARh puluhan juta rupiah per bulan.
• Pabrik memasang Capacitor Bank di LMVDP untuk menaikkan Cos φ. Di dashboard Anda, indikator Cos φ diberi warna hijau jika ≥ 0.85 dan merah jika < 0.85.

4. Current Transformer (CT) & Faktor Pengali

Arus motor ratusan Ampere diturunkan oleh CT ke standar 0–5A. Jika CT bertuliskan 500/5A, pengalinya adalah 100x. Jika di meter terbaca arus sekunder 1.5A, arus beban riil adalah 1.5 x 100 = 150 Ampere. Jika angka daya di dashboard meleset 100x lipat, penyebabnya adalah rasio CT belum di-setting di meter.

5. Akumulasi Energi (kWh), Biaya, & Emisi Karbon

• Energi (kWh) = Daya kW x Jam Operasi. Tarif industri rata-rata Rp 1.115 – Rp 1.500 / kWh.
• Berdasarkan standar ESDM grid Jamali, emisi karbon adalah 0.79 kg CO₂e per kWh.

KURIKULUM BELAJAR 2: PROTOKOL MODBUS & IT PT MUSASHI AUTO PARTS INDONESIA

Materi Belajar Wajib 2: Protokol Modbus & Jaringan IT Industri

Keahlian Komunikasi Data yang Membuat Anda Diakui Sebagai Engineer Otomasi Handal

1. Perbedaan Modbus RTU vs Modbus TCP

Karakteristik Modbus RTU (Serial RS-485) Modbus TCP (Ethernet LAN)
Media FisikKabel tembaga 2-wire twisted pair (Terminal A+ dan B-)Kabel LAN UTP Cat6 (Konektor RJ45)
Jarak MaksimalHingga 1.200 meter tanpa repeater100 meter per tarikan switch LAN
PengalamatanSlave ID (Angka 1 s/d 247)IP Address (misal 10.41.47.122) + Slave ID
Kecepatan9.600 s/d 115.200 bps100 Mbps s/d 1 Gbps (sangat cepat)
Port StandarCOM Port / Serial InterfaceTCP Port 502 (Standar IANA)

2. Holding Registers Schneider (Function Code 03)

Data meter disimpan di Holding Register:
• 3020: Voltase L-L Avg (Float32)
• 3000: Arus Ampere Total (Float32)
• 3060: Daya Aktif Total kW (Float32)
• 3084: Power Factor Total (Float32)
• 3204: Total Energi kWh Kumulatif (Float64 / Int64)

3. Big-Endian Float 32-bit (ABCD)

Angka float membutuhkan 2 register 16-bit (4 byte). Schneider menggunakan format Big-Endian (High Word First / ABCD). Jika dashboard membaca angka aneh seperti 1.42e-38, ubah parser ke Big-Endian Float.

4. Perintah Jaringan Terminal IT

• ipconfig : Mengetahui IP address laptop.
• ping 10.41.47.122 -t : Menguji koneksi fisik kabel tanpa henti.
• tracert [IP] : Menelusuri jalur hop switch IT yang dilewati.
• arp -a : Melihat daftar MAC address perangkat dalam satu switch.
